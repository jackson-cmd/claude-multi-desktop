How to use two Claude accounts at the same time on a Mac

Claude Desktop signs in to one account at a time, and opening it again only brings the same window forward. Here is how to keep a work account and a personal account open side by side.

Why Claude opens only one window

Claude Desktop is an Electron app, and Electron lets one copy run per data folder. Your sign-in, chats and settings live in ~/Library/Application Support/Claude. When you open Claude a second time, macOS finds the copy that already uses that folder and brings it to the front.

If a second copy uses a different folder, it runs on its own with its own sign-in. The --user-data-dir flag sets that folder, and open -n asks macOS for a new copy. claude-multi-desktop makes small launcher apps that do exactly this, so you never type the flags yourself.

Step 1: install it

brew install jackson-cmd/tap/claude-multi-desktop

It is one bash script with no dependencies, and you can read all of it before running it. No Homebrew, or would you rather not use Terminal? Other ways to install include a Mac installer, a disk image with a double-click app, and npm.

Step 2: add your second account

claude-multi-desktop add Work

This creates ~/Applications/Claude Work.app with a coloured icon, and an empty folder ~/Library/Application Support/Claude-Work that will hold this account's sign-in and chats. To pick the look, add --color HEX or --icon claude (your own Claude icon with a coloured letter badge); the home page has the details.

Step 3: open it and sign in

claude-multi-desktop open Work

A second Claude window opens with no account. Sign in with your other account. If the browser sends the sign-in back to the wrong window, quit the other Claude windows, sign in, then reopen them from their launchers. You only sign in once per account.

Step 4: add a launcher for your first account

claude-multi-desktop add Main --default

While another account is open, clicking the normal Claude icon only brings that window forward. Claude Main always opens the account you were already using, so put both launchers in the Dock.

Step 5: check what is open

$ claude-multi-desktop list
LAUNCHER               STATE  ACCOUNT FOLDER
Claude Main            open   ~/Library/Application Support/Claude
Claude Work            open   ~/Library/Application Support/Claude-Work

What stays separate, what is shared

Each account keeps its own sign-in, plan, chats, projects, Desktop settings and connectors. Claude Code in every account reads the same ~/.claude, so your skills, CLAUDE.md, memory and MCP servers are the same everywhere, and sessions in different accounts can message each other.

If work data must never reach a personal account, use a tool that isolates Claude Code too, such as claude-multiprofile.

Remove an account

claude-multi-desktop remove Work                # keep its sign-in and chats
claude-multi-desktop remove Work --delete-data  # delete its folder too

Your first account is never deleted by the tool.
