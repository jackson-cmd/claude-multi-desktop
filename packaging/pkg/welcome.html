claude-multi-desktop

Run several Claude Desktop accounts at the same time on this Mac. Each window keeps its own sign-in and chats, and Claude Code in every window shares one setup (~/.claude), so sessions in different accounts can message each other.

This installs:

  • Claude Multi Desktop in /Applications: double-click it to add, open, rename or remove accounts without Terminal.
  • the claude-multi-desktop command in /usr/local/bin, for Terminal users.

It never copies, patches or re-signs Claude.app. You need Claude Desktop in /Applications.
